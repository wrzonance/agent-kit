# Resume unfinished issues implementation plan

> Execute inline with regression tests first. The operator subsequently authorized commit, push, a draft PR and ak v2 version 0.1.1.

**Goal:** Make a fresh `ak plan` recover unfinished board work without duplicating live workers.
**Architecture:** Reuse run, transcript and git evidence; put completion assessment in the worker.
**Tech stack:** Bash, jq, git, gh; no dependencies.
**Spec:** `docs/superpowers/specs/2026-11-02-ak-resume-design.md`.

## Review focus

Cross-session ownership; recent untracked files with an old HEAD; API failure;
an expected path containing the wrong branch; stale evidence after a squash merge.
Each is exercised by Task 1's recovery suite. Dependency semantics remain intact.

## Execution record

Structs/interfaces: reuse run items; add top-level harness/session, no new state machine.
Change map: planner, recovery helper, shared transcript activity, worker prose and tests.
Spike: read-only tracing found collect also uses `issue_active` to satisfy queued
waves. Keep its PR-result semantics; fresh plans check PR state. No spike code retained.
Invariants: no duplicate live worker; no lost work; PR completion is not issue completion.

Regression cycle: original recovery suite failed 21/33 assertions on the original
implementation. The final focused suite passes 45/45, including later red/green
cases for live workers before setup, old live transcripts, same-second run order,
cross-harness ownership and safe archival of prior evidence.
Review: one fresh read-only review identified an unbounded running transcript;
its regression now confirms stale transcripts follow the existing hang threshold.
Ruling: collect's existing PR-level wave completion is unchanged; fresh planning
rechecks issue eligibility. Changing both together would broaden dependency policy.
Ruling: matched running transcripts and transcript-less worktrees use the same
20-minute inactivity threshold (`AK_WAIT_HANG_S`) used by `ak wait`. A stale match
does not hold an issue indefinitely; fresh activity still prevents takeover.

Final verification: `bash tests/v2/test-plan-recovery.sh` passes 45 assertions.
`tests/run-tests.sh --gates-only` exits 0 with ALL GREEN: this includes every v2
suite, ShellCheck and the repository static gates. `git diff --check` passes.
Publication uses `fix/resume-in-progress` and advances both v2 harness manifests
to 0.1.1. The main checkout and installed plugin cache are unchanged.
